# 令和国土適応構想（Japan Adaptation Vision / Project Shirahige）

> **「100mm/hの豪雨」と「超高齢社会」が同時に押し寄せる日本において、インフラの限界を認め、デジタル・福祉・都市構造を統合して人的被害をゼロにするオープンソース政策提言・設計プロトコル**

---

## 📌 なぜこのプロジェクトが必要なのか（背景）

1. **ハードインフラ（河川・下水道）の限界**
   * 気候変動により、1時間あたり100mmを超える規格外の局地的大雨（内水氾濫・線状降水帯）が多発しています。
   * 従来の「都市排水基準（50〜60mm/h）」をベースにしたコンクリートインフラの拡充だけでは、物理的空間および財政的コストの観点から防ぎきれません。

2. **「逃げ遅れ」と超高齢社会の現実**
   * 災害時における被害の多くは、高齢者や要介護者などの避難行動要支援者に集中しています。
   * 急激な増水時に屋外へ避難させること自体が命のリスクとなり、避難所生活による災害関連死も深刻な課題です。

3. **行政の「縦割り」による対策の遅延**
   * 「まちづくり・インフラ（国土交通省）」「医療・介護・福祉（厚生労働省）」「避難・防災計画（内閣府）」「システム（デジタル庁）」が分断されており、包括的な事前投資・事業化が進みにくい構造になっています。

---

## 💡 本構想が目指すソリューション（コア概念）

本構想は、「完璧に水を防ぐ」のではなく**「水があふれても、街が壊滅せず、生活と生命が維持される」**社会システムへの転換（適応・アダプテーション）を目指します。

[都市構造] 防災拠点型・高齢者住宅（現代版・白鬚東アパート）
×
[行政DX] 省庁横断・デジタル共通プラットフォーム（進捗可視化）
×
[広域連携] 副都心・コンパクトシティ政策との統合

### 1. 防災複合型・高齢者住宅（Project Shirahige）
* **コンテキスト**：東京都墨田区の「白鬚東アパート（巨大な防火壁・避難拠点）」のコンセプトを現代版に再定義。
* **構造**：
  * 高層・堅牢な構造（RC/SRC）を採用し、電気設備や自家発電機は上層階に配置。
  * 平時は高齢者向け住宅（サ高住等）および福祉・デイサービス拠点として機能。
  * 豪雨・浸水時は**「移動しない避難（自室での垂直避難）」**を実現し、周辺住民の緊急一次避難拠点（高台）として機能。
* **地方都市モデル**：高層化が難しいエリアでは、学校跡地や公共用地を活用した「かさ上げ（盛り土）×低層福祉拠点」で展開。

### 2. 省庁横断型デジタル共通窓口・データ基盤
* 自治体や民間事業者が「防災×福祉×都市計画」の複合事業を進める際、1つのデジタル窓口から一括申請・処理できるプラットフォーム（API）を策定。
* **進捗の可視化**：審査ステータス（国交省・厚労省・内閣府等）をデジタル上でトラッキング可能にし、行政手続きの停滞・後回しを防ぐ。
* **データ連携**：3D都市モデル（PLATEAU等）、ハザードマップ、介護・福祉施設データをレイヤー統合。

### 3. 広域防災・副都心構想との連動
* 東京の副都心エリア（さいたま新都心、立川、横浜等）や地方のコンパクトシティ拠点へ本モデルを集約。
* 被災時の行政機能・データバックアップと、広域避難・復旧拠点を一体化。

## 🤝 貢献方法（How to Contribute）

どなたでも参加可能です！専門知識の有無を問わず、様々な視点からのフィードバックを歓迎します。

1. Issueを立てる

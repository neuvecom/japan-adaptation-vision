## 📌 1. 設計の基本思想

### 1-1. 「浸水しない建物」ではなく「浸水しても機能が止まらない建物」
従来の都市排水基準（概ね 50〜60mm/h）を超える 100mm/h 級の豪雨では、建物周辺の冠水は避けられません。本構想では、**1階・地下が浸水することを前提**に、次の3点を守る建物を目標とします。

1. **命を守る**：入居者が建物内（自室・上層階）にとどまるだけで安全が確保される（移動しない避難）。
2. **生活を止めない**：電気・水・トイレ・昇降・通信・空調の最低限の機能を、外部からの支援なしで一定期間維持する。
3. **地域を守る**：周辺住民の緊急一次避難先（人工の高台）として受け入れ、白鬚東アパートのように「地域を背後から守る拠点」となる。

### 1-2. 白鬚東アパートからの継承と再定義

| 観点 | 白鬚東アパート（昭和・墨田区） | Project Shirahige（令和版） |
|---|---|---|
| 想定災害 | 大規模市街地火災（延焼） | 内水氾濫・外水氾濫、地震、猛暑、長期停電 |
| 建物の役割 | 連続する住棟が「防火壁」となり避難広場を守る | 建物が「高台・避難拠点」となり周辺住民と入居者を守る |
| 主な設備 | 防火シャッター、放水設備 | 高所受変電・自家発電、止水、上層階の生活維持設備 |
| 入居者像 | 一般世帯 | 高齢者・要介護者（サ高住等）＋平時の地域福祉機能 |

### 1-3. 設計目標（仮置き）

| 項目 | 目標値（仮） | 備考 |
|---|---|---|
| 想定浸水深 | 敷地の想定最大浸水深 ＋ 余裕高 0.5m 以上 | ハザードマップの想定最大規模（L2）降雨を基本とする |
| 機能維持期間 | **72時間（3日）以上**、目標 **120時間（5日）** | 外部からの燃料・物資補給が途絶える期間を想定 |
| 受入れ人数 | 入居者 ＋ 周辺住民（延床面積・共用部面積から算定） | 04_use_cases.md の規模別モデルで試算 |
| 居住階 | 想定浸水深より上の階のみ（原則 2階以上、低地では 3階以上） | ピロティ構造と組み合わせる |

## 🏗 2. 建物構成（ゾーニング）

浸水リスクに応じて、建物を垂直方向に3つのゾーンに分けて考えます。

```text
┌──────────────────────────────┐
│ 屋上：太陽光発電、屋上避難スペース、ヘリ・ドローン受取り │
├──────────────────────────────┤
│ 上層階（居住ゾーン）                                   │
│   高齢者住宅（サ高住等）の居室、見守り・ケア拠点       │
│   ★ 受変電設備・自家発電・蓄電池・受水槽・加圧ポンプ   │
│   ★ 地域避難者の受入れスペース（多目的室・共用廊下）   │
├──────────────────────────────┤  ← 想定浸水深＋余裕高
│ 低層部（浸水許容ゾーン）                               │
│   ピロティ（駐車場・駐輪場）、エントランス、           │
│   デイサービス・地域交流室（浸水時は上階へ機能移転）   │
└──────────────────────────────┘
```

### 2-1. ピロティ構造と低層部の考え方
* 1階は **ピロティ（柱のみの吹き抜け）または浸水しても支障の少ない用途**（駐車場、駐輪場、屋外倉庫）に限定します。
* 平時に使いたいデイサービスや地域交流室を1階に置く場合は、**浸水時に什器・機能を上階へ移せる運用計画**と、止水板・防水扉を組み合わせます。
* 1階の内装・設備は「水が引いた後に洗って復旧できる」仕様（耐水材料、コンセントの高位置化、床下配管の回避）とします。

### 2-2. 低層・平面型（地方都市モデル）への読み替え
高層化が難しい地域では、垂直方向の代わりに **地盤そのものを高くする** 考え方をとります。
* 敷地の一部を盛り土（かさ上げ）して「人工の高台」を造成し、その上に平屋〜3階建ての福祉拠点を配置します。
* 盛り土の天端高は、想定浸水深＋余裕高を基本とし、車椅子やストレッチャーで上がれる **緩勾配スロープ（1/12 以下、可能なら 1/15）** を複数方向に設けます。
* 詳細は [04_use_cases.md](./04_use_cases.md) の「地方都市モデル」を参照してください。

## ⚡ 3. 設備仕様：ライフラインを止めないための最小要件

「建物は無事でも、電気・水・エレベーターが止まって上層階の高齢者が孤立する（開かずの部屋化）」ことを防ぐのが本章の目的です。国土交通省・経済産業省「建築物における電気設備の浸水対策ガイドライン」（2020年）の考え方をベースに、高齢者住宅として上乗せすべき項目を整理します。

### 3-1. 電気（高所受電・非常用電源）

| 要件 | 最小仕様（案） | 推奨仕様（案） |
|---|---|---|
| 受変電設備（キュービクル） | 想定浸水深より上の階、または屋上に設置 | 2系統受電、または浸水時に低層部を切り離せる区分開閉器 |
| 非常用発電機 | 上層階・屋上に設置、**72時間**運転可能な燃料 | 120時間分の燃料、または中圧ガス（耐震性の高い導管）によるデュアルフューエル |
| 蓄電池・太陽光 | 共用部照明・通信・医療機器の保安電源として設置 | 太陽光＋蓄電池で日中の自立運転（燃料切れ後の最低限の電源） |
| 配線ルート | 幹線は上階から下階へ向かう「上から配る」構成 | 低層部の回路を系統ごと遮断でき、上層階だけ生かせる回路分け |
| 優先負荷 | 医療機器（在宅酸素・吸引器）、エレベーター1台、給水ポンプ、通信、共用照明 | 共用部の冷暖房（熱中症・低体温症対策の「避難室」1室以上） |

### 3-2. エレベーター（垂直移動の確保）
* **非常用電源への接続**：少なくとも1台は非常用発電機に接続し、要介護者・ストレッチャーの搬送に使えるようにします。
* **冠水時の運転制御**：最下階やピットが浸水した場合でも、**浸水していない上層階の間だけで運転を継続できる制御**（浸水検知による最下階停止・自動退避）を求めます。
* **機械室・制御盤の位置**：機械室レスの場合も、制御盤・巻上機が浸水しない位置にあることを条件とします。
* **代替手段**：エレベーター停止時に備え、階段避難用の担架・階段避難車を各階に配備し、スタッフの訓練を行います。

### 3-3. 給水・排水
* **受水槽・加圧給水ポンプ** は想定浸水深より上、または高置水槽方式として停電時も重力で給水できる構成とします。
* **飲料水の備蓄目安**：1人1日3リットル × 滞在人数（入居者＋受入れ避難者）× 72時間以上。
* **排水の逆流防止**：1階浸水時でも上層階のトイレ・排水が使えるよう、逆流防止弁、排水槽の高所化・止水、汚水ポンプの非常用電源接続を行います。
* **下水道が使えない場合の代替**：携帯・簡易トイレの備蓄（1人1日5回 × 日数を目安）と、マンホールトイレ・貯留槽の設置を検討します。

### 3-4. 通信・情報
* 館内放送・ナースコール・見守りセンサーを非常用電源回路に接続します。
* 光回線が途絶した場合に備え、**衛星通信（低軌道衛星等）またはモバイル回線の予備系統**を確保します。
* 建物の状態（浸水深、電源状態、滞在人数、要支援者数）を [02_digital_platform.md](./02_digital_platform.md) のデータ基盤へ送信できるようにします（「拠点ステータスAPI」）。

### 3-5. 空調・衛生
* 夏季の長期停電を想定し、**非常用電源で冷房できる「避難室」を各フロアまたは建物に1室以上**確保します。
* 感染症対策として、受入れスペースの換気能力と、発熱者用の区画を確保します。

## 🚶 4. 避難動線

### 4-1. 入居者：「移動しない避難」
* 原則として **自室にとどまること自体が避難** になるよう、居住階を想定浸水深より上に限定します。
* 自室待機が難しい入居者（医療機器使用者等）は、非常用電源の優先負荷が集まる **「ケア集約フロア」** へ館内で移動します。移動は発災前（警戒レベル3〜4相当）に完了させる運用とします。

### 4-2. 周辺住民：「人工の高台」への垂直避難
* 周辺住民が **浸水開始前に** 到達できるよう、敷地外周からの複数の進入口と、**24時間解錠できる屋外避難階段** を設けます。
* 車椅子・ベビーカー利用者のため、屋外スロープまたは非常用電源付きのエレベーターを避難動線に含めます。
* 受入れスペースは、入居者の生活空間と動線を分け、プライバシーと介護業務を妨げない配置とします。
* 自治体と **防災協定（緊急一次避難場所の指定）** を結び、受入れ条件（人数上限、開放判断、費用負担）を事前に定めます（[03_legal_finance.md](./03_legal_finance.md) 参照）。

### 4-3. 敷地周辺の危険箇所
避難経路の計画では、次の場所を避けるよう設計・案内します。
* アンダーパス（道路の立体交差部の凹部）、地下道、半地下駐車場
* 谷津（やつ）地形の谷底・くぼ地、旧河道
* 側溝・水路沿い（冠水時に見えなくなり転落の危険がある）

これらの位置情報は、[02_digital_platform.md](./02_digital_platform.md) で定義する避難ルート計算用データ項目として整備します。

## ✅ 5. 仕様チェックリスト（叩き台）

設計段階・既存建物の改修段階で確認する最小項目です。「防災複合型・高齢者住宅」として認定・補助の対象とする際の要件案としても使います。

- [ ] 敷地の想定最大浸水深を確認し、余裕高を加えた「設計浸水深」を設定した
- [ ] 居住階はすべて設計浸水深より上にある
- [ ] 受変電設備・非常用発電機・制御盤が設計浸水深より上にある
- [ ] 非常用発電の燃料が 72時間分以上ある
- [ ] 非常用電源に接続したエレベーターが1台以上あり、冠水時の運転制御がある
- [ ] 受水槽・給水ポンプが浸水しない位置にある、または重力給水できる
- [ ] 排水の逆流防止措置がある
- [ ] 非常用電源で冷暖房できる避難室がある
- [ ] 地域住民の受入れスペースと 24時間アクセスできる避難動線がある
- [ ] 自治体との防災協定、避難受入れ運用マニュアル、年1回以上の訓練計画がある

## 🔍 6. 未解決の論点（コメント募集）

* **既存建物の改修**：既存のサ高住・団地で受変電設備を高所に移す場合の、構造・費用・工期の現実的な水準は？
* **エレベーターの冠水時運転**：メーカー各社の対応状況と、既存機への後付けの可否は？
* **燃料の確保**：72時間を超える場合の燃料補給協定（石油販売事業者・自治体）はどう組むべきか？
* **避難者受入れの上限**：入居者のケアを維持しながら受け入れられる人数の算定方法は？
* **木造密集地域との関係**：地震・火災時の「防火壁」機能（白鬚東アパート本来の役割）を併せ持たせる場合の追加仕様は？

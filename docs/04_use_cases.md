# 自治体規模別モデル（大都市近郊／地方都市）

> **本書の位置づけ**：[01_urban_architecture.md](./01_urban_architecture.md)（建築）、[02_digital_platform.md](./02_digital_platform.md)（デジタル）、[03_legal_finance.md](./03_legal_finance.md)（制度・財政）を、自治体の条件に合わせて組み合わせた **導入モデルの叩き台**（ドラフト v0.1）です。
> 登場する「モデル市」は説明のための架空の自治体で、数値はすべて仮定値です。実在の自治体での適用検討・事例の共有を歓迎します。

---

## 📌 1. 条件の違いとモデルの選び方

東京と同じ「高層化」の手法をすべての自治体にそのまま当てはめることはできません。ボトルネックと強みの違いに応じて、**「上（高層）へ伸ばす」か「横（平面）へ広げる」か** を選びます。

| | 大都市近郊 | 地方都市 |
|---|---|---|
| ボトルネック | 土地がない（地価が高い） | 予算がない、住宅需要が限られる |
| 強み | 民間の開発需要が高い | 土地に余裕がある（公有地・学校跡地） |
| 防災の方向性 | 高層化による垂直避難拠点 | 盛り土（かさ上げ）と低層拠点の集約 |
| 主な事業スキーム | モデルA：民間主導＋インセンティブ | モデルB：公有地活用型PPP／モデルC：PFI |
| 連動する政策 | 副都心構想・広域防災拠点 | コンパクトシティ（立地適正化計画） |

### 1-1. 選定フロー（叩き台）

```text
Q1. 対象地域の想定浸水深は 0.5m 以上か？
 ├─ No  → 既存施設の耐水化（設備の高所化・止水板）を優先
 └─ Yes → Q2 へ
Q2. 半径 500m 以内に、想定浸水深より高い階を持つ堅牢な建物が十分にあるか？
 ├─ Yes → 既存建物の避難拠点化（防災協定＋設備補助）を優先
 └─ No  → Q3 へ
Q3. 地価が高く、民間の住宅需要があるか？
 ├─ Yes → 【モデル1】大都市近郊モデル（高層型）
 └─ No  → Q4 へ
Q4. 学校跡地・公有地など、まとまった土地を確保できるか？
 ├─ Yes → 【モデル2】地方都市モデル（盛り土＋低層型）
 └─ No  → 【モデル3】ニュータウン・団地再生モデル（既存ストック活用）を検討
```

## 🏙 2. モデル1：大都市近郊モデル（高層型）

### 2-1. 想定する地域
* 東京圏の低地（河川沿いの平坦な低地、かつての湿地帯）や、台地に刻まれた谷津（やつ）地形のくぼ地
* 人口密度が高く、木造住宅や低層アパートが多い住宅地
* 副都心・広域防災拠点（さいたま新都心、立川、横浜など）の周辺市街地

### 2-2. 施設構成（例：モデル市A）

| 項目 | 内容（仮定） |
|---|---|
| 敷地 | 駅から徒歩10分、民有地 2,000㎡、想定最大浸水深 2.0m |
| 建物 | RC造 7階建て、延床約 3,500㎡ |
| 1階 | ピロティ（駐車場）、エントランス、止水板付きの地域交流室 |
| 2階 | デイサービス、訪問介護事業所、地域避難者の受入れスペース（多目的室） |
| 3〜7階 | サ高住 60戸、見守り・ケア拠点、非常用電源付きの避難室 |
| 上層階・屋上 | 受変電設備、非常用発電機、受水槽、太陽光発電 |
| 受入れ能力 | 入居者 約70人＋地域避難者 約100人、72時間の自立運転 |
| 事業スキーム | 民間事業者が整備・運営、容積率緩和と設備補助（[03_legal_finance.md](./03_legal_finance.md) モデルA） |

### 2-3. ポイント
* **既存の高層マンション・タワーマンションとの役割分担**：周辺の既存高層住宅とも防災協定を結び、拠点を面的に分散させます。本モデルの建物は、特に **要配慮者（高齢者・障害者）の受入れと医療・介護の継続** を担う「ケア付き避難拠点」と位置づけます。
* **広域連携**：大規模災害時は、副都心の広域防災拠点に行政機能・データのバックアップを置き、拠点ステータスを [02_digital_platform.md](./02_digital_platform.md) の基盤で共有します。

## 🌾 3. モデル2：地方都市モデル（盛り土＋低層型）

### 3-1. 想定する地域
* 人口 5万〜20万人程度の地方都市で、平野部の浸水想定区域に市街地や集落がある地域
* 小中学校の統廃合で学校跡地が生まれている、または庁舎・公共施設の再編を進めている地域

### 3-2. 施設構成（例：モデル市B）

| 項目 | 内容（仮定） |
|---|---|
| 敷地 | 小学校跡地 15,000㎡（公有地）、想定最大浸水深 1.5m |
| 造成 | 敷地の一部 6,000㎡ を 2.0m 盛り土して「人工の高台」を造成、緩勾配スロープを3方向に設置 |
| 建物 | 高台上に平屋〜2階建ての福祉拠点群（校舎が耐震基準を満たす場合は改修して活用） |
| 機能 | 高齢者住宅 30戸、小規模多機能型居宅介護、デイサービス、地域食堂、防災備蓄倉庫 |
| 平時の外構 | グラウンドの残りを公園・駐車場・貯留機能を持つ広場（雨水の一時貯留）として利用 |
| 受入れ能力 | 入居者 約35人＋地域避難者 約300人（体育館の転用を含む） |
| 事業スキーム | 公有地の定期借地による民間整備（[03_legal_finance.md](./03_legal_finance.md) モデルB）、造成は公共 |

### 3-3. ポイント
* **高層ビルを新築するより安価**：土地取得費がかからず、低層構造のため建設費を抑えられます。
* **コンパクトシティとの一体化**：拠点を立地適正化計画の「都市機能誘導区域」に位置づけ、周辺に住宅・生活サービスを集約していくことで、国の支援を受けやすくします。
* **流域治水への貢献**：グラウンドの一部を雨水の貯留機能を持つ広場とし、拠点自体が地域の浸水被害を軽減する役割も担います。
* **移動手段の確保**：拠点までの距離が長くなりやすいため、デマンド交通・福祉車両による **発災前の早期移送（前倒し避難）** の運用をセットで計画します。

## 🏘 4. モデル3：ニュータウン・団地再生モデル（既存ストック活用）

### 4-1. 想定する地域
* 1970〜80年代に整備されたニュータウン・公的賃貸住宅団地で、住民の高齢化と建物・設備の老朽化が同時に進んでいる地域

### 4-2. 施設構成の考え方
* 団地の建替え・改修の際に、一部の住棟を **防災複合型の高齢者住宅（サ高住・ケア付き住棟）** に転換します。
* 既存住棟では、受変電設備の高所化、エレベーターの設置・非常用電源接続を優先的に改修します。
* 団地内の広場・集会所を、防災備蓄と地域の避難受入れ拠点として再整備します。
* 敷地に余裕がある場合は、建替え余剰地の一部を盛り土して高台化します。

## ⏱ 5. シナリオ：平常時／警戒時／発災時／復旧時

どのモデルでも、「平時は福祉拠点、非常時は防災拠点」として機能を切り替えます。

| フェーズ | 目安 | 入居者 | 地域住民 | 拠点・行政 |
|---|---|---|---|---|
| **平常時** | ― | 自室で生活、見守り・介護サービスを利用 | デイサービス、地域食堂、交流室を利用 | 避難訓練（年1回以上）、備蓄の更新、データ基盤への拠点情報登録 |
| **警戒時** | 大雨警報〜警戒レベル3 | 医療機器使用者をケア集約フロアへ移動、低層部の機能を上階へ移転 | 要配慮者の前倒し避難（福祉車両で移送） | 止水板の設置、発電機の点検、受入れスペースの開設、拠点ステータスの送信開始 |
| **発災時** | 警戒レベル4〜5、周辺冠水 | **自室にとどまる（移動しない避難）** | 屋外避難階段・スロープから上層階へ垂直避難 | 非常用電源で運転、受入れ人数・物資の不足をリアルタイムに共有、自治体災害対策本部と連携 |
| **復旧時** | 水が引いた後〜数週間 | 通常の生活・介護を継続 | 自宅の片付けの間、日中の休憩・入浴・食事の場として利用 | 低層部の洗浄・復旧、在宅の要配慮者の見守り拠点、復旧予算の申請（共通窓口で一括） |

## 📈 6. 導入ロードマップ（叩き台）

| ステップ | 内容 |
|---|---|
| **Step 1：現状把握** | ハザード・要配慮者の分布・既存の堅牢な建物をデータ基盤上で重ね合わせ、「避難拠点の空白地帯」を特定 |
| **Step 2：既存ストックの活用** | 既存の高層住宅・公共施設との防災協定、設備の耐水化補助から着手（短期・低コスト） |
| **Step 3：モデル事業（PoC）** | 前向きな自治体1〜2か所で、モデル1またはモデル2の拠点を整備し、一括申請と進捗可視化を試行 |
| **Step 4：評価と標準化** | 整備費・運営費・訓練結果を公開し、認定要件（01）、データ仕様（02）、補助スキーム（03）を改訂 |
| **Step 5：全国展開** | 立地適正化計画・地域防災計画への位置づけを進め、副都心・広域防災拠点のネットワークに接続 |

> **本書の位置づけ**：「防災複合型・高齢者住宅」と「デジタル共通窓口」を実現するための制度・財政面の叩き台（ドラフト v0.1）です。
> 制度名・補助率は執筆時点の一般的な理解に基づく整理であり、**最新の要綱・予算での確認が必要** です。コスト試算の数値はすべて **仮定値** です。

## 📌 1. 基本的な考え方：「ハイブリッド型」の役割分担

100mm/h 級の豪雨をすべてインフラで防ぐことは、費用と地下空間の両面から現実的ではありません。本構想では、リスクを次の3層で分担します。

| 層 | 担うもの | 主な手段 |
|---|---|---|
| ① インフラ（公共） | 計画規模（概ね 50〜60mm/h）までの雨を防ぐ | 下水道・河川整備、流域治水（貯留・浸透） |
| ② 建物・拠点（官民連携） | 計画規模を超えた雨で **人的被害をゼロにする** | 防災複合型・高齢者住宅、民間建物の避難拠点化 |
| ③ 制度・保険（公助・共助・自助） | 超過分の **経済的損失を分散する** | 被災者生活再建支援金、水災補償付き火災保険 |

本書は主に ② の実現手段（法制度・補助金・事業スキーム）と、その費用対効果を扱います。

## ⚖️ 2. 現行制度の整理

### 2-1. 関係する主な制度

| 分野 | 所管 | 主な制度（例） | 本構想での役割 |
|---|---|---|---|
| 住宅 | 国土交通省 | サービス付き高齢者向け住宅整備事業（スマートウェルネス住宅等推進事業） | 高齢者住宅本体の整備費補助 |
| 都市計画 | 国土交通省 | 立地適正化計画（防災指針）、都市構造再編集中支援事業 | 拠点を「居住誘導区域」「都市機能誘導区域」に位置づけ |
| 治水 | 国土交通省 | 流域治水関連法（特定都市河川浸水被害対策法等の改正、2021年） | 浸水被害防止区域、貯留機能保全区域との整合 |
| 建築 | 国土交通省 | 建築基準法（容積率不算入：防災備蓄倉庫・蓄電池・自家発電設備・貯水槽） | 防災設備の設置インセンティブ |
| 介護・福祉 | 厚生労働省 | 地域医療介護総合確保基金、地域介護・福祉空間整備等施設整備交付金 | デイサービス等の福祉機能の整備費 |
| 防災 | 内閣府（防災担当） | 災害対策基本法（指定緊急避難場所、避難行動要支援者名簿、個別避難計画） | 拠点の避難場所指定、要支援者の避難計画 |
| 被災者支援 | 内閣府 | 被災者生活再建支援法（全壊世帯に最大300万円） | 超過リスクの公的補償（③層） |
| デジタル | デジタル庁・内閣府 | 地方創生系の交付金（旧・デジタル田園都市国家構想交付金等）、自治体システム標準化 | 共通窓口・データ基盤の整備費 |

### 2-2. 一括申請を妨げている主な障壁（Issue #2 の整理）

1. **予算の所管別の区分**
   財政法・会計法のもとで、歳出予算は府省・項ごとに区分されています。ある省の予算を他省の審査基準で執行することは原則できず、「一つの窓口で一括採択」は現行のままでは難しい構造です。
2. **補助金適正化法と重複補助の禁止**
   補助金等に係る予算の執行の適正化に関する法律（補助金適正化法）のもとで、同一経費への重複補助は認められません。複合施設では、どの経費をどの制度に計上するかの **按分** が複雑になり、申請側・審査側双方の負担になります。
3. **補助要件・スケジュールの不一致**
   公募時期、採択時期、交付決定前着工の可否、補助対象経費の定義が制度ごとに異なり、「A省の採択後にB省の公募が締め切られていた」といったズレが事業の遅延・断念を生みます。
4. **施設類型の法的な位置づけ**
   「高齢者住宅」と「避難場所」と「福祉施設」を兼ねる建物は、各法令上の用途・類型の組み合わせになり、用途変更や避難者受入れ時の取扱い（定員超過、消防法上の収容人員等）が明確ではありません。

## 🧭 3. 法改正・制度改善の方向性

新しい省庁を設置する組織改編よりも、**手続きの統合と進捗の透明化（プロセスの改編）** を優先します。短期（現行法の運用改善）から中長期（法改正）へ段階的に進めます。

### 3-1. 短期：現行法の範囲で実施できること
* **パッケージ支援の運用**：社会資本整備総合交付金のように、複数事業を1つの計画で束ねて交付する既存の仕組みを参考に、関係省庁が **合同の相談窓口と共通様式** を設けます。
* **地域再生計画・特区制度の活用**：地域再生法の交付金一本化の仕組みや、総合特区・構造改革特区の特例措置を使い、モデル自治体で一括申請を試行します。
* **審査の標準処理期間の設定と公表**：各制度に標準処理期間を設け、[02_digital_platform.md](./02_digital_platform.md) の進捗可視化と組み合わせて滞留を公表します。

### 3-2. 中期：制度の新設・改正
* **「防災複合型高齢者住宅」認定制度の創設**：[01_urban_architecture.md](./01_urban_architecture.md) のチェックリストを要件とする認定制度を設け、認定を受けた事業は関係省庁の補助を **優先採択・一括審査** の対象とします。
* **容積率緩和の拡充**：地域住民の受入れスペース・屋外避難階段・高所設備室を容積率不算入または割増しの対象とし、民間事業者が防災機能を「持ち出し」ではなく「得になる」形で組み込めるようにします。
* **避難受入れ時の取扱いの明確化**：災害時に地域住民を受け入れた場合の定員超過・用途上の取扱い、事業者の責任範囲（免責）、受入れ費用の公費負担ルールを法令・通知で明確にします。

### 3-3. 長期：横断的な司令塔と財源
* **内閣府（防災担当）の調整権限の強化**：関係省庁の関連予算を一覧化し、重点配分を勧告・調整できる権限を持たせます（新たな防災担当組織が設置される場合はその所掌とします）。
* **横断型の交付金枠**：「防災×福祉×都市」の複合事業について、関係省庁の予算を持ち寄った統合的な交付金枠を設けることを検討します。

## 🤝 4. 補助金・PPP/PFI 事業モデル

地域の財政力や民間需要に応じて、次の3つのモデルを想定します。

### モデルA：民間主導＋インセンティブ型（大都市・大都市近郊）
* 民間事業者（サ高住事業者、デベロッパー、社会福祉法人）が建設・運営します。
* 公共側は **容積率緩和・建設費補助・防災設備補助** を提供し、その対価として **地域避難スペースの提供と自治体との防災協定** を求めます。
* 東京都の「東京とどまるマンション」のような、防災性能の登録と設備補助を組み合わせた既存の枠組みを発展させます。

### モデルB：公有地活用型PPP（地方都市・郊外）
* 学校跡地・庁舎跡地などの公有地を **定期借地** で民間事業者に貸し付け、土地取得費を抑えます。
* 盛り土（かさ上げ）など敷地の防災造成は公共側が行い、上物（福祉拠点・住宅）は民間が整備・運営します。
* 立地適正化計画の拠点に位置づけ、都市構造再編集中支援事業等の国の支援を組み合わせます。

### モデルC：PFI（BTO方式）型（公共施設の複合化）
* 自治体が発注者となり、設計・建設・維持管理・運営を一括して民間に委ねます（BTO：建設後に所有権を自治体へ移転）。
* 避難所・地域防災拠点・福祉施設など公共性の高い機能を中心に、サ高住等の民間収益施設を併設して事業全体の採算を確保します。

| | モデルA | モデルB | モデルC |
|---|---|---|---|
| 主な事業者 | 民間 | 民間（公有地を借地） | 民間SPC（PFI） |
| 土地 | 民間所有 | 公有地（定期借地） | 公有地 |
| 公共負担 | 補助金・容積率緩和 | 土地の低廉貸付・造成 | サービス対価の延べ払い |
| 向く地域 | 地価が高く住宅需要がある地域 | 土地に余裕がある地方都市 | 公共施設の再編を進める自治体 |

## 💴 5. コスト試算（簡易モデル）

### 5-1. 試算の考え方
防災機能の「上乗せ費用」を明示し、それによって避けられる損失（人的被害・復旧費・災害関連の医療介護費）と比較します。以下は **ロジックを示すための仮定値** であり、実際の見積り・統計に基づく検証を募集します。

**前提条件（仮定）**

| 項目 | 仮定値 | 備考 |
|---|---|---|
| 建物 | RC造 7階建て、サ高住 60戸＋1階デイサービス | 大都市近郊モデル（[04_use_cases.md](./04_use_cases.md)） |
| 延床面積 | 約 3,500㎡ | |
| 標準的な建設費 | 約 14億円 | 延床単価 40万円/㎡ と仮定 |
| 地域避難者の受入れ | 100人 | 共用部・多目的室の活用 |

### 5-2. 防災機能の上乗せ費用（仮定）

| 項目 | 仮定額 | 備考 |
|---|---|---|
| 受変電設備・制御盤の高所設置（構造補強・配管延長含む） | 3,000万円 | 標準配置との差額 |
| 非常用発電機（72時間燃料）・蓄電池・太陽光 | 5,000万円 | |
| エレベーターの非常用電源接続・冠水時制御 | 1,000万円 | 1台分 |
| 受水槽・ポンプの高所化、逆流防止、簡易トイレ備蓄 | 1,500万円 | |
| 止水板・防水扉、ピロティ化による床面積調整 | 2,000万円 | |
| 地域避難スペース・屋外避難階段・備蓄倉庫 | 3,500万円 | |
| **合計** | **1億6,000万円** | **標準建設費の約 11%** |

### 5-3. 費用負担のイメージ（モデルA、仮定）

| 負担者 | 仮定額 | 根拠となる仕組み（案） |
|---|---|---|
| 国の補助（住宅・防災系） | 8,000万円 | 上乗せ費用の 1/2 を補助 |
| 自治体の補助 | 4,000万円 | 上乗せ費用の 1/4 を補助 |
| 事業者負担 | 4,000万円 | 容積率緩和による増収で回収 |

### 5-4. 便益の考え方
* **人的被害の回避**：入居者（高齢者 60〜70人）と地域避難者（100人）が、危険な屋外移動をせずに安全を確保できます。
* **災害関連死・入院の回避**：避難所生活での体調悪化や、要介護度の悪化に伴う医療・介護費を抑えます。
* **復旧費の低減**：受変電設備等の水没を避けることで、設備の交換費と長期の機能停止を防ぎます。
* **平時の価値**：福祉・地域交流拠点としての利用、建物の資産価値・入居率の向上。

防災分野では、事前の防災投資1に対して数倍の被害軽減効果があるとする国際的な試算がよく引用されます（倍率は研究・対象によって異なり、本書では具体的な倍率を前提にしません）。本構想の試算では、次の式で自治体・地域ごとに評価することを提案します。

```text
純便益 ＝ Σ（年超過確率 × 回避できる損失額） × 耐用期間の現在価値係数 ＋ 平時の便益 − 上乗せ費用

  回避できる損失額 ＝ 人的被害の回避価値 ＋ 設備・建物の復旧費の回避額
                    ＋ 災害関連の医療・介護費の回避額 ＋ 行政の避難所運営費の回避額
```
